# Contributing

Issues and pull requests are welcome for code, tests, and documentation.

1. Open an issue for substantial changes; keep pull requests focused.
2. Run `ruff check .` and `python -m pytest` before submitting.
3. Do not commit patient-level cohort files, controlled-access data, credentials, or other sensitive information. Do not include identifiable data in issues or pull requests.
4. Keep data-source terms and scientific limitations explicit. Do not describe synthetic demo performance as biological validation or imply clinical use.
5. Use a feature branch and a clear commit message; submit changes through a pull request.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

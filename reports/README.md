# Reports

The [Phase 2B report](phase_2b_training_cv.md) records training-only four-fold cross-validation. The [Phase 2C report](phase_2c_validation.md) records the frozen validation evaluation and describes the test as locked **at that historical phase**. The [Phase 3D aggregate report](phase_3d_aggregate_results.md) describes the subsequent completed, one-time held-out evaluation using approved aggregate results.

Historical phase reports retain their original chronology. Full arrays, fitted models, patient-level predictions, authorizations, claims, and sealed audit artifacts remain local and are not published here.
